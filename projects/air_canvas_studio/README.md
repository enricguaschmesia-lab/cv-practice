# Air Canvas Studio

Standalone computer vision test project for hand-tracking based drawing interactions.

## Run

- `python projects/air_canvas_studio/AirCanvasStudio.py`

## Assets

- Local model file: `projects/air_canvas_studio/models/hand_landmarker.task`

## Notes

- This project is kept as a separate test project under `projects/`.
- Shared helper scripts and prototypes remain under `experiments/scratch/`.
