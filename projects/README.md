# Projects

This directory contains complete computer vision test projects.

- `assistive_gesture_control/`: Assistive Gesture Control Platform (AGCP).
- `air_canvas_studio/`: AirCanvasStudio interactive drawing project.

Design intent:
- Each project keeps its own configs/docs/tests/assets under its folder.
- Each project keeps its own source code under its own folder (for example, `assistive_gesture_control/src/`).
- New projects should follow the same structure for consistency.
